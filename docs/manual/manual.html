Antes de tudoComo ler este manual

Este sistema conversa com pessoas usando um modelo de linguagem, e isso tem uma consequência prática que precisa ficar clara antes de qualquer outra coisa.

A regra que evita o falso defeito

O texto que a IA escreve muda a cada execução. O comportamento observável do sistema não muda.

Se você mandar “quero comprar um apartamento” duas vezes, vai receber duas redações diferentes da mesma pergunta. Uma hora ela pergunta “Qual região você está procurando?”, outra hora “Em qual bairro você gostaria de morar?”. As duas estão corretas, porque as duas perseguem o mesmo campo.

Por isso este manual não manda você digitar uma frase e conferir se a resposta bateu palavra por palavra. Ele dá frases de partida, deixa você conversar do seu jeito, e diz o que observar: qual etiqueta apareceu, qual campo o painel preencheu, quando o seletor de data surgiu, se os imóveis respeitaram o orçamento.

Quem tenta validar a redação da IA conclui que o sistema está quebrado. Quem observa o comportamento vê que ele está funcionando. A seção 7 detalha exatamente o que olhar.

Caminho mais curto, se você só quer ver funcionando

  1. Instale as dependências uma vez: seção 2.
  2. Se quiser a IA de verdade, pegue a chave: seção 3. Sem ela o sistema roda igual, com respostas mais robóticas.
  3. Suba os dois terminais: seção 4.
  4. Abra http://localhost:5173 e converse: seção 7.

O resto do manual existe para quando alguma coisa não fizer sentido, e para quem vai avaliar e precisa saber o que procurar.
